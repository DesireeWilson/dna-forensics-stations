# DNA & Forensics Science Stations

Interactive stations for a public science outreach table:

1. Station 1 – video (QR code)
2. Station 2 – **The Dee N. Ay Show**, a paternity-test game (`paternity.html`)
3. Station 3 – video (QR code)
4. Station 4 – **Bone Detective Lab**, hands-on bone ID and skeletal profile (`bones.html`)
5. Station 5 – **The Bones of Briar Hollow**, a forensic mystery (`mystery.html`)

Plain HTML pages with no build step, hosted on GitHub Pages.
